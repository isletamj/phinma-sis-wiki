# Configuration

The **Configuration** module is where school administrators set up the people,
accounts, and system-wide options that the rest of the SIS depends on. Most
onboarding tasks start here: adding students and employees, creating their login
accounts, defining roles and access, and configuring options like the student
consent form.

## Pages in this section

- [Add Student](/docs/configuration/add-student) — upload student records and
  create their login accounts
- [Employee Masters](/docs/configuration/employee-masters) — manage the titles,
  positions, and other lookup values used across employee records
- [Add Employee](/docs/configuration/add-employee) — onboard faculty and staff
  into the system
- [Bulk Employee User Creation](/docs/configuration/bulk-employee-user-creation) —
  create SIS login accounts for many employees at once
- [User Creation](/docs/configuration/user-creation) — create and manage staff
  user accounts
- [Terms & Conditions Configuration](/docs/configuration/terms-and-conditions-configuration) —
  set up the student privacy agreement and consent form
- [Change Password](/docs/configuration/change-password) — reset your own account
  password
- [User Log Details](/docs/configuration/user-log-details) — review user login
  sessions and page activity
- [Role-Based Access](/docs/configuration/role-based-access) — define roles and
  control what each user can see
