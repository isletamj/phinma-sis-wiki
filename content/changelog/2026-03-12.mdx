title: Grade encoding reports and DP grade reversion
date: 2026-03-12
---

This release adds new grade encoding and academic/awardee reports, DP grade
reversion and updated final grade logic, a login activity log and log deletion
report, plus several reporting, attendance, classroom, and storage enhancements
across schools.

<Section title="New">
- **Grade encoding reports:** Added a new grade encoding reports page for all schools
- **DP grade reversion feature:** Added DP grade reversion feature along with interim backend adjustment for all schools
- **Login page activity log:** Added activity log on the default login page
- **Academic awardees SHS report:** Added academic awardees report for SHS with both semestral and yearly approach; includes GWA computation with honors qualification threshold
- **Log deletion report:** Added report for tracking log deletion activity
- **Final grade computation:** Added new final grade computation logic
</Section>

<Section title="Improvements">
- **Course transfer – DP max session:** Course transfer now displays DP max session instead of enlistment count for all schools
- **Course-wise attendance report:** Added additional columns to the course-wise attendance report for SJC
- **Classroom assignment report:** Applied minor formatting changes to the classroom assignment report
- **Co-teacher attendance editing:** Co-teachers can now edit attendance records when attendance is unlocked *(SWU)*
- **Exam Excel file storage:** All exam Excel files are now uploaded and stored in Blob storage
</Section>
