# PHINMA SIS Wiki

Guides for using the PHINMA Student Information System (SIS) — what each page is
for and how to use it, written for the administrators and staff who run the
system day to day.

The documentation is organised by module. Pick a section to get started:

- [Configuration](/docs/configuration) — set up students, employees, users,
  roles, and system-wide options
- [Academics](/docs/academics)
- [Examinations](/docs/examinations)
- [Finance](/docs/finance)
- [Student Details](/docs/student-details)
- [University Setup](/docs/university-setup)
- [SIS Support](/docs/sis-support)
- [Processes](/docs/processes)

Only **Configuration** is fully written up so far — the other sections are on
their way.
