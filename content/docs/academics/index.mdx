# Academics

The **Academics** module covers academic-year setup, the sectioning and scheduling
groundwork a term is built on, and the retention and scholarship tools that
enrollment and admissions processes depend on.

## Pages in this section

- [Academic Session](/docs/academics/academic-session) — create school years and the
  sessions inside them, and map those sessions to the colleges that use them
- [Intake Creation](/docs/academics/intake-creation) — create and manage intake
  records, including the Intake Code used for Student ID generation
- [Attendance Configuration](/docs/academics/attendance-configuration) — set the
  attendance window, the lock period, and the SMS, email and lesson plan facilities
  for a term
- [Time Slot Configurations](/docs/academics/time-slot-configurations) — define the
  shifts, slots, period times, and time slot groups the class timetable is built from
- [Room Configurations](/docs/academics/room-configurations) — register the
  buildings, floors, room types and rooms that classes are scheduled into
- [Sectioning](/docs/academics/sectioning) — create section codes, map them to a
  campus, college and course, and maintain batch labels
- [Section Offering](/docs/academics/section-offering) — open sections for an
  academic session with a shift, slot, modality and capacity, and publish them to
  students
- [Block Section Teacher](/docs/academics/block-section-teacher) — assign a teacher
  and any co-teachers to every subject a block section carries
- [Create Class Schedule](/docs/academics/create-class-schedule) — lay a section's
  subjects out across the week, with a room and teacher for each class
- [Copy Section Offer](/docs/academics/copy-section-offer) — carry an existing
  session's section offerings over to another session or campus
- [Subject Wise Capacity Change](/docs/academics/subject-wise-capacity-change) — set
  the seat limit of a single subject inside a section
- [Holiday/Event Entry](/docs/academics/holiday-event-entry) — declare the calendar's
  non-teaching days and, where required, cancel the classes that fall on them
- [Auto Advising Configuration](/docs/academics/auto-advising-configuration) — decide
  which curricula and semesters let regular students enlist without advisor approval
- [Retention Policy](/docs/academics/retention-policy) — configure the
  three-strike, fail-twice, and GRR rules and send advisory reminders
- [SWU Retention Policy](/docs/academics/swu-retention-policy) — SWU's separate
  Academic Eligibility policy, with deloading and disqualification rules
- [External Bulk Scholarship Tagging](/docs/academics/external-bulk-scholarship-tagging) —
  create external scholarship records and tag students to them in bulk via Excel
