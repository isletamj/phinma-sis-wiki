# Final Grade Release

## Overview

The **Final Grade Release** page lets Deans officially release final grades to
students after teachers have completed grade encoding. Once released, grades become
visible to students and can be reflected in official records.

<Callout type="info">
  The grade release process works **teacher-wise**. Each teacher's grades can be
  released independently — you no longer need to wait for all co-teachers assigned
  to the same subject to finish encoding before releasing any grades.
</Callout>

## How to Access

1. Log in to the SIS portal using your Dean account.
2. From the main menu, navigate to **Examinations** → **Final Grade Release**.

## Understanding the Page

The page shows a grid of courses pending grade release, with these columns:

| Column | Description |
| --- | --- |
| **Check Box** | Selects rows for grade computation and release. |
| **Report** | Downloads a report showing the grade computation per student. |
| **View** | Expands the row to show students and their grade summary. |
| **Semester** | Current semester of the students. |
| **Teacher Name** | The teacher assigned to that subject and section. |
| **Subject Code / Name** | Identifier and description of the subject. |
| **Status** | Encoding status (e.g. Complete, Incomplete). |
| **Date** | When the subject was computed and released. |

<Callout type="info">
  Because grades release **per teacher**, you may see the same subject listed more
  than once when multiple teachers handle different sections or groups. Each row is
  one teacher's set of grades.
</Callout>

## Releasing Final Grades

<Steps>

#### Filter the records

Use the filters at the top — **Academic Session**, **Campus**, **Curriculum**,
**Exam Pattern**, and **Learning Modality** — then click **Show** to load the
results.

#### Review the list

Check that the **Status** column shows encoding is complete for the rows you intend
to release.

<Callout type="important">
  You can release grades for a teacher even if another teacher assigned to the same
  subject hasn't finished encoding. Each teacher's submission is handled
  independently.
</Callout>

#### Select records to release

Check the box beside the rows you want to release, or use the header checkbox to
select all visible rows.

#### Compute and release

Click **Compute & Release Grade**. On the confirmation prompt, click **Yes**. The
grades become visible to students and the status changes from **Pending** to
**Released for Students**.

</Steps>

## Generating the Final Grade Release Report

Apply the filters (Academic Session, Campus, Curriculum, Exam Pattern, Learning
Modality), click **Show**, then click the report icon to download. The report
includes student details, subject details, teacher/faculty name, grades given by
faculty, converted and weighted grades, and final grades and remarks.

## Unreleasing Grades

If grades were released in error, unrelease them via **Examinations → Overall
Unrelease Grade**. That page also displays data **teacher-wise**, so you can
pinpoint which teacher's grades to reverse.

<Callout type="warning">
  Unreleasing a grade makes it invisible to students again and lets the teacher make
  corrections and recomputations before re-releasing.
</Callout>

## Frequently Asked Questions

**I can't find a subject in the grade release list. What should I check?**
Confirm the correct Academic Session and Semester are selected, that the teacher has
completed encoding for all enrolled students, and that the subject is under your
college's jurisdiction.

**I see the same subject listed twice. Is that a bug?**
No. This is expected when a subject has multiple teachers assigned to different
sections — each row represents one teacher's set of grades.

**Can I release grades for all teachers of a subject at once?**
Yes — if all teachers for a subject have completed encoding, select all their rows
and release them together.

**A teacher says their grades were released but students can't see them yet.**
Ask the teacher to confirm the subject and section, and check the release status on
this page or the teacher-wise grade report. If it persists, coordinate with the
Registrar's Office or raise a support ticket.

**Can I release grades if some students have incomplete components?**
No. All grade components for all enrolled students must be encoded by that teacher
first. The system shows an alert if encoding is incomplete for a teacher's section.
