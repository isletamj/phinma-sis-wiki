---
title: Reporting and admin tools
date: 2025-12-29
---

This release adds new reporting and admin tools (password reminders, data
fetching, returnee and document reports, counter controls, DP exemption
cancellation, and schedule conflict notifications), improves access and exports,
and fixes a Student Data Report issue.

<Section title="New">
- **Password reminder:** Added password reminder for faculty and students in the profile popup
- **Fetch button:** Added a `Fetch` button on the `Program Credits` page to retrieve data from `Subject Curriculum Mapping`
- **Returnee report:** Added `Report For Students - RETURNEE` in the Grade Encoding Report page
- **Counter activation:** Added functionality to activate or deactivate a counter
- **Document submission report:** Added report showing documents submitted by students
- **Cancel DP exempt:** Added functionality to cancel submitted DP exemptions
- **Conflict management:** Added page to configure which faculties receive conflict management notifications when setting up schedules
</Section>

<Section title="Improvements">
- **Removed restriction:** Faculty advisors are no longer the only users who can view student profile pages
- **Department column:** Added `Department` column to the `User Creation` exported report
- **DP grade:** `DP` grades can now be assigned to any subject
- **Admission date:** Form 137 now uses First Class Schedule Date instead of Admission Date
- **Password management flow:** Expired Password → Password Reset OTP → Password Reset → Login → Single Login OTP
</Section>

<Section title="Bug fixes">
- **Section column:** Now reflecting in `Student Data Report`
</Section>
